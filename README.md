# sequana-lora-demo

Demo site for the [sequana_lora](https://github.com/sequana/lora) pipeline — part of the [Sequana](https://github.com/sequana/sequana) project.

**Live site:** https://sequana.github.io/sequana-lora-demo

## What is this?

This repository hosts example HTML reports generated by `sequana_lora`, a
Snakemake pipeline for *de novo* assembly of long-read sequencing data
(ONT, PacBio HiFi). The reports were produced from PacBio HiFi reads of
*Streptococcus* (1 full sample + 4 sub-sampled datasets).

The demo site is intended to let users explore the pipeline outputs without
having to run the pipeline themselves.
